# Capability Matrix

AI Store Developer should become an all-round Shopify development agent.

## Supported Input Types

- natural language
- screenshot
- image mockup
- Figma design
- reference URL
- Shopify resource
- theme/template
- code snippet
- bug/error log

## Safety Classes

### Class A — Read Only

Can be automated after authentication.

### Class B — Low-Risk Reversible Write

Requires approval.

### Class C — Theme / Code Change

Requires:

- diff
- backup
- validation
- approval

### Class D — Destructive / High Impact

Requires enhanced confirmation and stronger restrictions.

## Product Rule

AI proposes.

Server-side policy authorizes.

Merchant approves.

Execution engine applies.
